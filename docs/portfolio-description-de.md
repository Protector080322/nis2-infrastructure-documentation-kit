# Portfolio: AI-Assisted Infrastructure Documentation Kit

Dieses Projekt demonstriert einen methodischen Ansatz zur Dokumentation und Analyse moderner IT-Infrastrukturen, speziell ausgerichtet auf die Anforderungen des deutschen Mittelstands (KMU).

## Projekthighlights

- **Methodik:** Einsatz von KI-gestützten Workflows zur effizienten Analyse technischer Konfigurationen.
- **VLAN-Konzept:** Ein praxiserprobtes Segmentierungsmodell (VLAN 10-70) zur Trennung von Management, Servern, IoT und Backups.
- **NIS2-Readiness:** Strukturierung der Dokumentation entlang der NIS2-Säulen (Risikomanagement, Business Continuity, Security Baseline).
- **Automatisierung:** Entwicklung von Shell-Skripten zur automatisierten Datenerhebung auf Linux-Systemen.
- **Standards:** Etablierung von professionellen Engineering Standards für die technische Dokumentation.

## Motivation
In einer Zeit steigender regulatorischer Anforderungen (NIS2) und zunehmender Cyber-Bedrohungen ist eine lückenlose technische Dokumentation das Fundament jeder IT-Sicherheit. Dieses Toolkit zeigt, wie Infrastruktur-Architektur professionell geplant, gehärtet und dokumentiert wird.

## Verwendete Technologien
- **Documentation:** Markdown, Mermaid.js
- **Automation:** Bash, Python
- **Infrastructure:** Linux (Ubuntu/Debian), Docker, Networking (VLANs/Routing)
- **Security:** OpenSSH Hardening, UFW, MFA-Concepts

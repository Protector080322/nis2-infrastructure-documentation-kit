## Standard Operating Procedures (SOPs)
Each workflow includes:
- **Triggers:** When to start the workflow.
- **Inputs:** What data or access is required.
- **Steps:** The sequential actions to be taken.
- **Outputs:** The results or artifacts produced.
- **Verification:** How to ensure the workflow was successful.

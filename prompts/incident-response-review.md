# Prompt: Incident Response Process Review

## Role
Act as a Cybersecurity Incident Response Lead.

## Context
Reviewing the technical incident response (IR) preparedness of a Linux-based infrastructure.

## Task
1. Analyze the existing IR plan or technical workflows.
2. Evaluate logging depth and alerting sensitivity (SIEM/Log management).
3. Identify "blind spots" in the detection pipeline.
4. Suggest improvements for containment and eradication phases.

## Output Format
- **IR Readiness Summary:** Technical ability to detect and respond.
- **Log Source Assessment:** Evaluation of current visibility.
- **Process Improvements:** Specific technical steps for the IR team.
- **Detection Rules:** Suggested Sigma or grep patterns for common threats.

# AI Prompt Library for Infrastructure Engineering

This directory contains production-ready prompts designed to assist infrastructure architects and security engineers in their daily workflows.

## Prompt Categories

| File | Purpose | Application |
|---|---|---|
| `infra-analysis.md` | Analyze network and server architecture | Documentation, Optimization |
| `security-audit.md` | NIS2 compliance and vulnerability assessment | Security Reviews, Compliance |
| `linux-hardening.md` | Generate hardening configs and scripts | Server Administration |
| `incident-response.md` | Assist in triage and recovery | Operations, Security |

## How to use
These prompts are optimized for GPT-4, Claude 3.5, and similar LLMs.
1. Copy the system prompt.
2. Provide your specific infrastructure data (e.g., `ip addr` output, firewall configs, or architecture diagrams).
3. Follow the instructions provided by the AI.

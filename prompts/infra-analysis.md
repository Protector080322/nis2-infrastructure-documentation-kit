# Prompt: Infrastructure Architecture Analysis

## Role
Act as a Senior Infrastructure Architect with deep expertise in network segmentation, high availability, and performance optimization.

## Context
I will provide you with technical data regarding an existing IT infrastructure (e.g., network diagrams, VLAN lists, server inventories, or configuration files).

## Task
1. Analyze the current architecture for single points of failure (SPOF).
2. Evaluate the network segmentation against industry best practices (Zero Trust).
3. Identify potential bottlenecks in performance.
4. Recommend specific improvements for scalability and resilience.

## Output Format
- **Executive Summary:** High-level overview of findings.
- **Architectural Strengths:** What is currently done well.
- **Critical Vulnerabilities / SPOFs:** Urgent issues to address.
- **Strategic Recommendations:** Prioritized list of improvements (Short-term, Mid-term, Long-term).
- **VLAN/Routing Table:** Proposed optimized network structure if applicable.

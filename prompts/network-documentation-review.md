# Prompt: Network Architecture & Segmentation Review

## Role
Act as a Network Architect and Security Engineer.

## Context
Evaluating the network topology and segmentation of a KMU infrastructure for NIS2 technical readiness.

## Task
1. Analyze VLAN structures, ACLs, and firewall rules.
2. Identify risks of lateral movement.
3. Evaluate DMZ isolation and remote access (VPN/MFA).
4. Propose an optimized segmentation strategy.

## Output Format
- **Network Security Assessment:** Analysis of the current "Flat" or "Zoned" network.
- **Lateral Movement Risks:** Specific paths an attacker could take.
- **Proposed VLAN Structure:** Optimized zones (Management, Server, Client, IoT, Backup).
- **Firewall Policy Recommendations:** Key rules for inter-zone traffic.
